## Original Request (verbatim)

> Actually getting our agents to use skills (under .claude/commands) organically, without me having to do it all the time! /reasoning:run to best examine what to do.

## Interpreted Intent

Raise the rate at which agents — primarily Alpha, also Beta/Gamma/Delta — invoke existing skills under .claude/commands when the user's request matches a skill's purpose, without the user typing the slash command. User explicitly requested /reasoning:run as the first step to evaluate mechanism candidates.

## Desired Outcome

The existing skill library becomes high-leverage by default. Operators stop having to remember which slash command applies; Alex picks it. The user's manual-prompting overhead drops.

## Affected Surfaces

| Surface | Evidence Level | Notes |
|---|---|---|
| CLAUDE.md | verified_from_repo | Agent identity + behavior rules. Likely amendment target. |

## Current Behavior

- Evidence level: `verified_from_repo`
- Skills are user-invocable slash commands. Smart-context enriches prompts with memory but does not surface relevant skills. CLAUDE.md mentions skills only in passing; no explicit 'prefer skills' rule. Agents discover skills only through the system-reminder skill list, which is long and unranked.

## Desired Behavior

When the user's prompt or current task matches a skill's purpose, the relevant skill is surfaced to the agent with high signal (system-reminder, additionalContext from smart-context, or a heuristic router). The agent then invokes it organically. Manual invocation by the user remains a no-op override.

## Scope

- Size: `m`
- Risk: `medium`

### Variants

- **Minimal safe:** Run /reasoning:run to pick approach. Then add a small set of high-leverage skill-use directives to CLAUDE.md + lexicon (e.g., 'when a user asks for X, prefer skill Y'). No code changes. Measure adherence in one session.
- **Recommended:** /reasoning:run produces a written recommendation. Implement: (a) CLAUDE.md amendment with a 'prefer existing skills' rule; (b) smart-context.js enrichment that ranks top-3 relevant skills against the prompt (Haiku call already in pipeline) and injects them as additionalContext. Adherence logged.
- **Expanded:** Above + a learning loop (track skills surfaced vs invoked, score adherence, adjust weights), a friction-driven proposer (if user types steps a skill could've done, suggest the skill mid-session), a skill-metadata audit + improvement pass.
