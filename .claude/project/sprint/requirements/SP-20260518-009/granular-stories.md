## S-1 — Rename WARPOS_ROADMAP.md → ROADMAP.md (content move)

**As** the framework owner
**I want** the framework backlog content moved from `WARPOS_ROADMAP.md` into `ROADMAP.md` (overwriting the existing 40-line scaffold-decoration file)
**So that** the canonical repo has one roadmap file with the real content. Git history must show this as a delete + rename rather than two unrelated diffs — use `git rm ROADMAP.md` first, then `git mv WARPOS_ROADMAP.md ROADMAP.md` (or two-step staging that preserves the move).

While renaming, strip the obsolete header HTML comment (lines 3-7 of the prior `ROADMAP.md`) and the obsolete footer cross-link (lines 35-39). Replace them with a single short header HTML comment explaining the dual identity of `ROADMAP.md`:

- In canonical WarpOS = framework backlog.
- In consumer projects = product roadmap; the scaffold is generated by `scripts/warpos/generate-roadmap-scaffold.js`; `promote.js` excludes this file from propagation.

Linked: `H-1`, `R-1`, `R-3`.
