## H-1 — As the maintainer, I want one VS Code task per portfolio product so I can spawn a labelled terminal pane in 3 keystrokes.

**As** the user
**I want** As the maintainer, I want one VS Code task per portfolio product so I can spawn a labelled terminal pane in 3 keystrokes.
**So that** Maintainer can switch between WarpOS-the-framework and N product repos via Ctrl+Shift+P → 'Run Task' → 'Claude: <slug>' (3 keystrokes).
