## Policy-block encoding (R2 three-kind taxonomy)
Each D1 policy block ends with ONE machine-parseable trailer line; G0.1 parses the leading token:
- `Enforcer: scripts/checks/<x>.js` — enforceable-now; ref MUST resolve.
- `Deferred: ED-NNN @ Phase-X-exit` — enforced-later; ED MUST exist + name the phase where binding flips. NEVER a dangling `Enforcer: future.js`.
- `Core: non-waivable` — CORE invariant; enumerated in the §7 CORE list; `waivable:false`; the ED hatch is refused.
G0.1 rejects any block with no trailer, an unresolvable `Enforcer:`, a non-existent `ED-NNN`, or a `Core:` block that also carries a `Deferred:` (contradiction).
