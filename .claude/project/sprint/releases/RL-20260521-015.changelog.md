# RL-20260521-015 — /product:clone skill

**Sprint:** SP-20260520-001 · **Target:** internal · **Version label:** `skill-clone-1.0.0` · **Risk:** low

## What changed

Added a new operator skill `/product:clone` that performs competitor-product intelligence in one invocation, replacing days of manual competitive research. Given a target product (name or URL), the skill discovers public surface, extracts jobs-to-be-done, scores features by build complexity and core-ness, gathers voice-of-customer quotes with attribution, and surfaces gaps + opportunities. Output materializes at `_docs/clones/<slug>/`.

- **New skill:** `/product:clone` in `.claude/commands/product/clone.md`.
- **New generator:** `scripts/product/clone.js` with two phases:
  - **Discovery phase (shipped):** SSRF-guarded fetcher, public-surface enumeration, cache layer, output emission, telemetry, partial-deliverable handling on network failure.
  - **LLM-extraction phase (runtime-only, deferred):** JTBDs, features, voice-of-customer, gaps, opportunities. Tickets T-20260521-147 (WebSearch product-id), T-151..T-155 (5 extraction passes) marked `deferred` in tracker — they execute when operator invokes the skill, not in test harness. Real-world validation deferred to first operator invocation.
- **New templates:** `framework/templates/product-clone/` (output skeleton, section blocks).
- **New paths:** `paths.clones` (`_docs/clones/`) and `paths.clonesCurrent` (`_docs/clones/<slug>/`) registered in `.claude/paths.json`.
- **New telemetry:** event types for clone lifecycle (start, surface-discovered, extraction-pass-*, output-emitted, cache-hit, partial-deliverable-emitted).

## Non-goals

- No human reviewer of LLM extractions inside the skill — output quality is gated by operator review post-run, not by automated assertion.
- No persistent crawl history — cache is per-target, ephemeral; not a discovery database.
- No competitor-specific heuristics — extraction prompts are general, not tuned per industry.

## Rollback

Skill is additive. `git revert <sprint-merge-commit>` removes the skill, generator, templates, and path keys. Cached fetches and operator outputs under `_docs/clones/<slug>/` are user data — operator removes manually. No persisted state outside that dir, no migration.
