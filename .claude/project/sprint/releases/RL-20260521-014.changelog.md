# RL-20260521-014 — /product:import skill

**Sprint:** SP-20260520-002 · **Target:** internal · **Version label:** `skill-import-1.0.0` · **Risk:** low

## What changed

Added a new operator skill `/product:import` that generates a paste-friendly questionnaire (Markdown) from local project context (PROJECT.md, README, package.json, recent commits) so another AI session — Claude Code, Codex, Claude web, ChatGPT web, or Gemini web — can answer detailed questions about a product trapped in a non-Claude-Code project. Answers flow back to `/product:bootstrap --answers-file` to materialize a proper requirements set.

- **New skill:** `/product:import` in `.claude/commands/product/import.md`.
- **New generator:** `scripts/product/import.js` with two modes:
  - `emit` (default) — introspects local context, renders questionnaire to `_docs/imports/<slug>/<slug>.questionnaire.md`, paste-compatible across 5 AI surfaces.
  - `--parse <answers.md>` — round-trip mode: ingest filled-in answers, validate 8-section parity against bootstrap schema, emit `_docs/imports/<slug>/<slug>.answers.parsed.json` ready for `/product:bootstrap --answers-file`.
- **New templates:** `framework/templates/product-import/` (questionnaire skeleton, section blocks, paste-test fixtures).
- **New paths:** `paths.imports` (`_docs/imports/`) and `paths.importsCurrent` (`_docs/imports/<slug>/`) registered in `.claude/paths.json`.
- **New telemetry:** 6 event types — `import_started`, `context_introspected`, `questionnaire_emitted`, `parse_started`, `parse_completed`, `parse_failed_section_mismatch`.
- **Section parity probe:** `node scripts/product/import.js --probe` returns `section_parity: true` confirming questionnaire sections map 1:1 to `/product:bootstrap` schema.
