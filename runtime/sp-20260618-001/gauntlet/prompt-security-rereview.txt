# SP-20260618-001 SECURITY RE-REVIEW — path-traversal fix (U2 seed-provenance writer)

You previously FAILed scripts/warpos/views/populate-seed-provenance.js with a MEDIUM
path-traversal / write-outside-target finding: populateSeedProvenance() trusted opts.zones and
wrote path.join(targetRoot, zoneRel, ".provenance.json") without rejecting "..", absolute paths,
drive-qualified paths, or symlink/junction escapes (confirmed: zones:["../..."] escaped + a _docs
junction escaped).

The security-fixer applied TWO layered guards (diff below):
1. STATIC: zoneRejectReason(zoneRel, allowedZones) — rejects absolute / drive-qualified / rooted /
   ".."-containing / non-member zones, validated against scaffold-core.SKELETON_DIRS (the trusted
   constant, NOT opts.zones).
2. REALPATH: deepestExistingAncestor() + fs.realpathSync — requires the marker's parent to stay
   under realpath(targetRoot), defeating symlink/junction escape.
Tests added: ../escape (reported in failed + nothing written + ok=false) and junction (escape
detected, nothing written). The full test now passes 14/14 (was 9).

+function zoneRejectReason(zoneRel, allowedZones) {
