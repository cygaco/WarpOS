WarpOS's IDENTITY + AUTHORITY provider-portable and un-forgeable. Max risk = HIGH: the irreversible failure is

the worker reads, NEVER the authority for its binding. The precedence graph:
  explicit_user -> validated_workorder_or_cli -> explicit_top_level_helm -> UNBOUND(FAIL_CLOSED).
A dispatched_worker is bindable ONLY via validated_workorder_or_cli; it NEVER defaults to President (alex-alpha).
The top-level human session defaults to alex-alpha ONLY via an explicit helm binding, never via ambient prose.
